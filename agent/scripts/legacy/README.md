# Legacy experiments

Pre-v1 scripts from the Strix box, kept for reference (full history on the
`strix-history` branch). They are not installed, tested or linted as part of
the package and will be deleted once the v1 server covers the same ground.

- `yolo_ws_server.py` — WebSocket frame stream → YOLO-World, GPU-synced telemetry to SQLite
- `run_yolo.py` — YOLO on a local video/camera with crop capture
- `hand_states.py` — MediaPipe hand landmarks over WebSocket
- `telemetry_analysis.py` — latency vs resolution plots from the telemetry DBs
